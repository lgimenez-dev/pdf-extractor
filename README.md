# PDF Extractor

A cross-platform (Windows and Linux) command-line tool to extract the
content of a PDF file: **embedded images** and **plain text**.

Built in Python with [PyMuPDF](https://pymupdf.readthedocs.io/), which
extracts images in their original format and resolution (no recompression
or rescaling) and text preserving the reading order of each page.

## Features

- Extracts embedded images preserving their original format (PNG, JPEG, etc.)
- Extracts the plain text of each page to a plain text (`.txt`) file
- Both extractions are optional and independent (`--images`, `--text`)
- Works from the command line or in interactive mode (no arguments)
- Cross-platform paths (Windows / Linux) handled with `pathlib`
- Per-image error handling: if one fails, the rest are still extracted

## Installation

Requires Python 3.10 or higher.

```bash
git clone <repo-url>
cd extractor-pdf
python -m venv venv

# Activate the virtual environment
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

## Usage

**Extract images and text (default behavior):**
```bash
python main.py -i file.pdf -o ./output
```

**Extract images only:**
```bash
python main.py -i file.pdf -o ./output --images
```

**Extract text only:**
```bash
python main.py -i file.pdf -o ./output --text
```

**Interactive mode** (no arguments; prompts for the paths in the console):
```bash
python main.py
```

### Output

```
output/
├── images/
│   ├── page001_img01.png
│   └── page001_img02.jpg
└── text.txt
```

## Arguments

| Argument | Short | Description | Default |
|---|---|---|---|
| `--input` | `-i` | Path to the input PDF | *(required or interactive)* |
| `--output` | `-o` | Output folder | `./output` |
| `--images` | — | Extract images only | — |
| `--text` | — | Extract text only | — |

If neither `--images` nor `--text` is given, both are extracted.

## Why PyMuPDF

PyMuPDF is built on MuPDF (Artifex's engine), which is very mature and
tolerant of malformed PDFs or those generated by non-standard software.
Instead of rendering the page as a screenshot, it directly accesses the
image objects embedded in the PDF, so the extraction preserves the exact
original resolution and quality.
